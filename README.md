# LLM Sampling

This repository explores sampling techniques used in Large Language Models (LLMs) for generating text.

## Overview

The notebook demonstrates how different sampling strategies can influence the output generated by a language model. It provides a practical understanding of how controlling randomness affects text generation.

## Technologies Used

* Python
* Jupyter Notebook
* Hugging Face Transformers
* Large Language Models (LLMs)

## Project Structure


LLM-Sampling/
│
└── llm-sampling.ipynb


## Getting Started



Open the notebook using Jupyter Notebook or Google Colab and run the cells sequentially.

## Learning Objectives

* Understand LLM text generation
* Explore sampling-based generation
* Observe how sampling parameters affect generated text
* Experiment with different generation settings
